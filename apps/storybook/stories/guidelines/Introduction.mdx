# EverGreen Design System (Desktop)

Welcome to the EverGreen Design System documentation. This Storybook serves as the single source of truth for:

- **Developers** — component APIs, props, and usage examples
- **Designers** — visual specs, tokens, and interaction patterns
- **Product** — usage guidelines and accessibility expectations

## Getting started

### Install components

```bash
pnpm add @evergreen/components
```

### Import styles and components

```ts
import '@evergreen/components/style.css';
import { EgButton, EgTypography, EgIcon } from '@evergreen/components';
```

### Theme support

Apply a theme by setting `data-theme` on the root element:

```html
<html data-theme="light">
<!-- or -->
<html data-theme="dark">
```

Or use the built-in composable:

```ts
import { useThemeProvider } from '@evergreen/components';

const { theme, setTheme, toggleTheme } = useThemeProvider();
```

## Design tokens

Token specs live in `packages/tokens/spec/` (scale, typography, text, color, effect).

After updating spec files from Figma:

```bash
pnpm build:tokens
```

## Package structure

| Package | Purpose |
|---------|---------|
| `@evergreen/tokens` | Design tokens → CSS variables |
| `@evergreen/components` | Vue 3 components (CSS Modules) |
| `@evergreen/storybook` | Documentation & component playground |

## Figma integration

1. Add your Figma file key to `figma.config.json`
2. Update `packages/tokens/spec/*.json` from Figma variables
3. Rebuild tokens with `pnpm build:tokens`
