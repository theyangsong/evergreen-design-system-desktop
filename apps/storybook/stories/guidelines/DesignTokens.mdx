# Design Tokens

EverGreen tokens are authored in `packages/tokens/spec/` and built to CSS via `pnpm build:tokens`.

## Token systems

| System | Spec | CSS output |
|--------|------|------------|
| Scale | `spec/scale/` | `--spacing-*`, `--radius-*`, `--stroke-*`, `--icon-*` |
| Typography | `spec/typography/` | `--eds-*` (semantic roles), `--eds-family-sans` |
| Text Styles | `spec/text/styles.json` | `.typography-*` classes via `@eds/desktop-tokens/text/styles` (also in main `typography` bundle) |
| Color | `spec/color/` | `--text-*`, `--material-*`, `--box-*`, `--event-*` |
| Tag | `spec/color/tag-palette.json` | `--tag-status-*`, `--tag-colorful-*`, `--tag-custom-*` (separate from Color System) |
| EDS Effect | `spec/effect/` | `--eds-shadow-*`, `.effect-molde-level`, `.effect-flotation-box`, … |

EDS Effect mirrors Color: `effect/themes/light/` and `effect/themes/dark/` each contain `base.css` (variables) + `semantic.css` (classes). Light values resolve from the light color palette; dark from dark.

Import order: `scale → typography → color → tag → effect`

```css
@import '@eds/desktop-tokens';
```

## Usage in CSS Modules

```css
.myComponent {
  color: var(--text-base-primary);
  background: var(--material-card-moderate);
  padding: var(--spacing-4);
  border-radius: var(--radius-md);
  font-size: var(--eds-body-medium-size);
  line-height: var(--eds-body-medium-line-height);
}
```

Prefer **Text Style classes** when applying a full Figma role (size + weight + line-height together):

```css
/* HTML / Vue template */
<p class="typography-body-medium">…</p>

/* CSS Modules — compose global Text Style */
.label {
  composes: typography-body-medium from global;
  color: var(--text-base-primary);
}
```

Use individual semantic variables only when you need to override one axis (e.g. body-medium size with a different weight):

```css
.myComponent {
  font-size: var(--eds-body-medium-size);
  line-height: var(--eds-body-medium-line-height);
}
```

Text Style classes ship from `@eds/desktop-tokens/text/styles` and are included in `@eds/desktop-tokens` / `@eds/desktop-tokens/typography`.

## Figma sync workflow

Linked file: [EverGreen Design System (Desktop)](https://www.figma.com/design/OkYrDmatUWtgw9n1uVHt6v/EverGreen-Design-System--Desktop-)

Variable collections in Figma:

- **Color System** — Text, Stroke, Material, Primitives (`eds-base`, `eds-brand`, …)
- **Scale System** — Primitives / Scale-0 through Scale-20

1. Open the Figma file
2. Compare variables with `packages/tokens/spec/*.json`
3. Update spec JSON files
4. Run `pnpm build:tokens` to regenerate CSS

Check sync status: `pnpm sync:tokens`
